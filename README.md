## 📖 简介

**QuiteRSS-R** 是基于 QuiteRSS 项目复刻而来的开源 RSS 阅读器，使用 AI 编写。目前仅提供 **Windows** 平台的预编译版本。

在界面与功能上，QuiteRSS-R 与 QuiteRSS 几乎完全相同，仅对部分内容进行了优化和修整。

> 💡 **提示**：因 QuiteRSS 已停止开发，本 R 版**不会进行功能性开发**。如需功能性开发，请见 QuiteRSS-S。

---

## ✨ 特性

- 🗂️ **配置目录互相独立，但配置文件完全通用**
- 🌙 **基于暗色模式，新增了两款外观**
- 🔤 **纠正了简体中文语言模块中的许多错误翻译，使用主流翻译进行替换**
- 🎨 **双版本差异**（见下方对比）
